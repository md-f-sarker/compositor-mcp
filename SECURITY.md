# Security policy

## Supported versions

Only the latest release and the default branch receive security fixes.

## Reporting

Report suspected vulnerabilities privately via **GitHub's private vulnerability
reporting**: [Security → Report a vulnerability](https://github.com/md-f-sarker/compositor-mcp/security/advisories/new).

Include affected commit, reproduction steps, impact and any suggested mitigation.
Do not include real bridge tokens, private images or project files.

Please allow time for validation and a coordinated fix before public disclosure.
